# Quyết định

Mỗi quyết định của nhóm là một file `NNN-ten-ngan.md` (ví dụ `001-nganh-cong-ty.md`), mở bằng PR sau
khi issue **Decision** đã chốt. Đã chốt thì không sửa nội dung; đổi ý thì viết file mới và ghi
"Thay cho NNN".

```markdown
# NNN. <Tên quyết định>

- Ngày: <yyyy-mm-dd> · Issue: #<n>

## Bối cảnh
<Vì sao phải chọn, ràng buộc nào.>

## Các phương án
<Mỗi phương án một dòng, kèm được và mất.>

## Chốt
<Chọn gì.>

## Hệ quả
<Việc gì thay đổi, việc gì phải làm thêm.>
```
